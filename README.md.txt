# Bike Sales Dashboard — Excel

## Overview

This project is an Excel-based data analysis and dashboard project
completed as part of my data analytics learning portfolio.

The project demonstrates the use of Microsoft Excel for data preparation,
analysis, visualization, and dashboard creation.

## Tools Used

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- PivotTables
- Data Visualization
- Dashboard Design
